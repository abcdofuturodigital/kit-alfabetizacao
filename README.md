# Kit Alfabetização — ABC DO FUTURO DIGITAL

Repositório da página de vendas do Kit Alfabetização.

## Produto

Kit digital de materiais pedagógicos para apoiar a alfabetização.

### Materiais
- Caderno de Sílabas Simples
- Caderno das Vogais
- Caderno de Coordenação Motora (50 páginas)
- Bônus: Livro de Colorir — Animais da Fazenda

## Oferta
- Preço do kit: R$ 34,90
- Valor dos materiais separados: R$ 49,70
- Economia: R$ 14,80
- Checkout Hotmart: https://pay.hotmart.com/G108080766B?checkoutMode=10&bid=1792293294853

## Desenvolvimento
- Aplicação em React + Vite.
- Código e alterações mantidos no GitHub.
- Não utilizar o agente do Lovable para editar o projeto.
- As páginas reais dos materiais serão incorporadas quando forem enviadas.
- Os mockups atuais são provisórios e devem ser substituídos pelas capas/páginas reais antes da publicação final.

## Visualização local
```bash
npm install
npm run dev
```

Para gerar a versão de produção:
```bash
npm run build
```
